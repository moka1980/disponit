# PR-005a: lagring og kontrakter (M-37-skjema, migrasjonsherding, kryptering, attestasjonsbinding)

**Draft: Claude.ai (PR-005) · GO fra ChatGPT · Implementering: Claude Code · Branch: `pr-005-m37-api`**

PR-005 er delt i to etter eiers beslutning. **Dette er 005a: alt som ikke
rører nettverket.** API-inngangen (`kjerne.behandle()`, `app.py`,
feilveitabellen, lasttesten) kommer i **005b**, sammen med
manifest-formatet og ytelsesporten.

Begrunnelsen for delingen: PR-004 var én PR med flere uavhengige
leveranser og tok seks review-runder med tolv P1. Sju leveranser i én PR
gir en review-flate der feil gjemmer seg.

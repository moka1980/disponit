# Disponit handoff

Dette notatet er bevisst kort fordi detaljene skal hentes fra selve repoet.

Når Codex starter i Disponit:

1. Les `README`, `AGENTS.md`, package-/Python-konfig og siste git-status.
2. Finn hvordan prosjektet kjøres lokalt.
3. Ikke start på nytt.
4. Ikke gjør store designendringer uten å sjekke eksisterende stil.

Standard første melding:

```text
Les prosjektet først og forklar kort arkitektur, hvordan det kjøres lokalt, og hvilke tester som finnes. Ikke endre kode før du har oversikt.
```
